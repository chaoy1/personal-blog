首页「每日一句」纸带右端那个圆钮。

现状：陶土粉渐变饼 + 一圈粗灰环 + 右上红点。环线太重，两层圆彼此较劲，红点与缺口位置对不上；连点时过渡被反复重置、整圈转满又弹回原点。

↓ 推荐方向可以直接连点试手感

推荐 · 纸印与一支笔锋

连点试试：转得越来越快，松手后缓慢收势

连点 0 次
当前速度 0.00 圈/秒
累计转过 0.00 圈
角度单调递增，永不停顿回跳

为什么这样才不会顿：不再用「每次加一整圈 + CSS transition」，改成一个小型的陀螺模型 —— 指针用 requestAnimationFrame 连续积分， 每次点击只加一次速度（有上限）。速度按每帧衰减，所以连点会持续加速、松手后自然收势，全程角度单调递增，不存在过渡被重置，也不会转满一圈弹回起点。
