实现要点

为什么不能用 ~

组件把每枚分隔符放在每个链接之后，所以：
右邻 = 它自己的下一个兄弟 → a:hover + .nav-divider
左邻在悬停元素之前，+ 与 ~ 都够不到，必须反向指认 → .nav-divider:has(+ a:hover)
若用 a:hover ~ .nav-divider，会把被悬停项右边所有菱形全部点亮（实测 4 枚），这就是之前只亮一半的原因。 
.nav-divider {
  width: 4px; height: 4px; flex: none;
  border: 1px solid var(--rule-strong);
  transform: rotate(45deg);
  opacity: .78;
  transition: border-color .22s ease, box-shadow .22s ease,
              opacity .22s ease, transform .22s ease;
}

/* 紧邻的左右两枚一起染朱 */
.nav-links a:hover + .nav-divider,
.nav-links .nav-divider:has(+ a:hover) { border-color: var(--seal); opacity: 1;
  transform: rotate(45deg) scale(1.35);
  box-shadow: 0 0 0 2px color-mix(in srgb, var(--seal) 16%, transparent); }

/* 鼠标直接停在菱形上 */
.nav-links .nav-divider:hover { /* 同上 */ }

/* 键盘 Tab 也有同样反馈 */
.nav-links a:focus-visible + .nav-divider,
.nav-links .nav-divider:has(+ a:focus-visible) { border-color: var(--seal); opacity: 1; }

此方案已实现在 app/refinement.css，并由 tests/site-nav-divider.test.tsx 守护。
