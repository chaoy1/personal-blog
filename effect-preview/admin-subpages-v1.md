# 后台子页面设计图：山窗案头

总目录：http://127.0.0.1:3016/effect-preview/admin-designs-v1.html

本次一次交付七个独立子页面；现有总览通过左侧导航连接到子页。所有文件位于 `effect-preview/`，沿用已确认的深松绿书脊、米黄哑光纤维纸、鸿雷行书与朱印。尚未修改正式 `/admin` 路由、登录权限、数据库或 API。

| 页面 | 独立 HTML | 设计与可操作演示 |
| --- | --- | --- |
| 文章管理 | `admin-posts-v1.html` | 独立纸卡组成篇目册，侧栏篇目夹；标题/摘要/slug 搜索、状态筛选、本地排序、回收站与恢复、确认操作、跳转编辑/阅读 |
| 文章编辑 | `admin-editor-v1.html` | 大幅手稿纸与设置边注；篇名、slug、摘要、Markdown 正文，快捷插入、正文预览、四种写作底色、专心写作、草稿保存、发布确认 |
| 文章预览 | `admin-article-preview-v1.html` | 阅读纸页与页边目录；标题、摘要、正文、草稿状态、章节跳转，返回编辑保留演示稿 |
| 闲语管理 | `admin-moments-v1.html` | 正文/配图/发布三个清晰区域，散页短笺列表；计数、选择本地图片、多图移除、仅图片发布、编辑/取消、删除五秒撤销、分页 |
| 光影管理 | `admin-photos-v1.html` | 底片目录与相册纸封套；照片库、相册、上传暂存三工作区；搜索/归属/排序、前后移动、说明编辑、相册新建编辑删除、图片暂存与示例收录 |
| 博主资料 | `admin-profile-v1.html` | 落款、自序与实时资料卡并列；昵称、头像、正文、安全文字预览、最近一稿还原、资料保存、首次建档字段演示 |
| 后台登录 | `admin-login-v1.html` | 青绿山窗与入室笺；密码显示隐藏、错误反馈、加载与完成状态，完成后进入总览设计图 |

每页使用 `admin-subpages-v1.css/js` 共用外壳，并有自己的 CSS/JS。原有 `admin-desk-overview-v1.css` 提供主题、导航与基础字体，`admin-paper-fibers.svg` 提供哑光纸面。页面的主体构图各有特色，统一纸色、边缘与软投影；以独立卡间距和明确的纸板层次区分模块，不增加浮动书签、塑料亮斑、画轴或入场展开。

鼠标交互集中在纸卡微升、卷角、轻微倾斜与方向投影，题签保持端正。减少动态效果模式取消位移与动画；触屏不启用指针倾斜。表单有明确标签，对话框支持 Escape，编辑器支持 Ctrl/⌘ S 保存本页示例。

## 真实功能依据与设计边界

- 参考 `app/admin/page.tsx`、`editor/page.tsx`、`preview/[id]/page.tsx`、`moments/page.tsx`、`photos/page.tsx`、`profile/page.tsx` 与 `login/page.tsx`，以及现有上传、草稿、预览组件。没有虚构文章分类或封面字段。
- 文章列表排序是本地设计演示。编辑器只覆盖现有标题、链接、摘要、正文与发布字段，未实现生产的自动同步、冲突恢复或完整 Markdown/GFM 渲染；链接与图片语法在简化预览中作为文字显示。
- 编辑器与阅读页通过本地 URL 参数传递已保存示例稿；无持久化存储。其他列表、账户建档与登录均为内存状态；刷新恢复。登录演示不验证身份，密码值不会保存或发送。
- 图片只生成本地 objectURL，或使用仓库已有山水资产；不上传。删除相册保留照片并移入未归类。没有接入生产上传队列、网络错误重试或数据库。
- 资料页简化预览支持标题、段落与引用，正式关于页仍沿用生产的 Markdown 渲染。头像上传后可还原最近保存稿，未保存头像不会覆盖保存稿的资源。
