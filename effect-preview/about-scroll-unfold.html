你好，我是这间小屋的主人。

平日里写代码，也写一些关于生活、成长和思考的文字。偶尔拍照，记录路过的风景；偶尔停下来，把那些不愿遗忘的瞬间整理成篇。

我喜欢简单而长久的事物：一本反复翻阅的书，一段认真完成的代码，一次没有目的的散步，以及人与人之间真诚的交流。

建立这个博客，并不是为了给生活下结论，只是想为走过的时间留下些许痕迹。这里有文章、闲语和光影，也可能有尚未想明白的问题。

如果其中某一段文字恰好与你产生共鸣，欢迎留下只言片语。山水有相逢，来日皆可期。

三处是量出来才改对的

① 首页那条缓动不能直接搬。一开始我沿用了首页画卷的 cubic-bezier(0.52, 0.02, 0.18, 1)。逐拍量下来它把 82% 的行程压进第 4→6 拍（360ms），剩下 600ms 停在 100%：放到横向 100vw 画卷上那是个漂亮的「甩」，放到竖向展一张 800px 的纸上就成了抽搐。

起手迟滞（纸有自重）、中段肯走、收尾长缓 —— 手卷被手拉着展开就是这个手感。

② 卷太薄就读不出「卷」。第一版开场把纸裁到只剩 30px，1:1 放大一看，天杆与地杆几乎贴在一起，合成了一根粗木条。改成 --roll: 64px，两根轴之间才露得出那卷纸。

③ 印盖在了空落款上。第一版把「用印」排在「落款显影」之前，顿印那一刻画面上只有一枚印，字还没出来 —— 顺序倒了。现在是先落款、再扫笔触、最后用印。

木料与配饰

花纹：第一版木料用的是一圈等距条纹，后来虽换成噪声，缩到全览尺寸仍像一根光滑的棕色塑料棒。现在改为哑光胡桃木：纹理沿杆身缓慢弯曲，在节疤旁绕行，两端木色也不完全相同。

  • wood-rod-grain.svg 把不等距的长纹、两处不对称节疤、木色渐变与细纤维合成一块连续纹理；在不同杆宽下随杆身拉伸，不出现贴图接缝。
  • 柱面保留上缘暖光和下缘暗部，中央不再铺整条亮白高光；低饱和棕眼与细纹使表面更接近未厚涂漆的木料。

配饰：

  • 车木轴头（四端）：clip-path 雕出束腰、鼓腹、收尖的轮廓，贴杆处以暗氧化边和一线暖光表现旧铜包口；不再使用白色镜面反射。
  • 近端双刻线：杆身两端各压两道深浅不同的细刻线，随天杆、地杆一同移动和退场。
  • 朱红丝绦（天杆两端）：一颗小珠打的结、一根细绳、穗子上收下散。挂在天杆两端，位置落在卡片之外、山水之上，不压正文。
  • 轴头与丝绦都比杆身大，所以投影没用 box-shadow（会被 clip-path 裁掉），改在杆身上用 filter: drop-shadow() —— 这样杆、轴头、丝绦各自投出自己的影子。

配饰只在展开过程中在场：收轴时随两根轴一起淡出，静止状态下页面上不会多出任何硬件。

为什么是立轴，不是长卷

首页展的是长卷（横轴，木轴自左向右把画面卷走）。关于页若也用横轴就是首页的重复。关于页是一页自序 + 落款 + 用印，对应的物件是立轴：竖着挂起来、自上而下展开。同一套语汇与拍子，换一个物件、换一根轴。

顺带一提：站里 globals.css 那套 .scroll-unfold / .su-paper / .su-roll（约 400 行 + opening-scroll-day/night.png）目前没有任何 .tsx 渲染，是死代码。它里面的木料配方（.su-roll-paper / .su-cap）也是横向条纹那一类，本方案没有沿用。

落地要动的位置

  1. app/about/page.tsx：把 PageIntro + article.content-sheet 包进 <div className="about-unfold-paper">，并在 main.about-scroll 里补三个兄弟节点：天杆、卷边、地杆。
    这一层包壳是必须的 —— clip-path 会把地杆一起裁掉，轴必须站在裁切区外面。
  2. app/studio.css：把第 2、3、4 节整段贴进「关于页」那一节末尾。
  3. components/AboutUnfold.tsx（新增，客户端组件，约 30 行）：
    • 不需要量任何尺寸 —— 展轴、轴、卷边全部用百分比，卡片写多长都对得上，也不会因为字体晚加载而错位
    • 「每次加载只完整播一次」：照 ScrollFX 里 heroPlayedInThisLoad 的模块标记法，客户端路由返回时给 .about-page 挂 data-unfold="done" 直接落终态
    • 跳过：动画期间 scroll / keydown / pointerdown 任意一个，同样挂 data-unfold="done"，浏览器直接落到终态
  4. lib/motion-policy.ts：直接复用现成的 shouldPlayFullUnfold({ reduced })，不新增判断。

降级

  • prefers-reduced-motion: reduce → 全套 animation: none，零动画，直接是读完的样子（面板上的「终态」就是模拟这个）。
  • 坑：光摘动画还不够。让两根木轴退场的是 about-rod-away 这个动画本身，只写 animation: none 的话，木轴会永久留在页面上 —— 降级态反而比动效态多出两根木头。所以 reduced-motion 里必须显式补 opacity: 0; visibility: hidden（已实测：rodTop / rodBottom / curl 均为 0 / hidden，clipPath: none）。
  • CSS 里动画是无条件声明 + both 的，所以首帧就处在「合着」的状态，服务端直出的 HTML 不会先闪一下整张纸。这也是首页 hero 的做法。
  • 唯一重音只有印，其余全是显影。若嫌 3.00s 长，把拍长调到 96ms 即 2.4s，节拍比例不变。
  • 性能提示：卡片投影用的是外层 filter: drop-shadow()（只有这样影子才会跟着裁切后的轮廓走）；木轴也用 drop-shadow 是为了让轴头与丝绦各自投出自己的影子。低端机上若嫌开销大，可改成静态 box-shadow 配一次淡入。

配饰为什么是静止的

丝绦挂上去之后，本来最容易顺手加的就是「让它轻轻摆」（死代码里 .su-ribbon 就有一整套摆动 keyframe）。没加 —— 那是第二条持续运动，会和主运动抢注意力。配饰该做的是把木料交代清楚，不是自己动起来。全片依然只有一个动作（向下展轴）和一个重音（用印）。
