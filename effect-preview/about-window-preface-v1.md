# 关于页 · 山窗小序

预览：[about-window-preface-v1.html](http://127.0.0.1:3016/effect-preview/about-window-preface-v1.html)

独立 HTML 设计图，沿用现有关于页的五段自序、`ChoyChou` 落款及头像地址。新增文字为章节标题、装帧题字与页面入口说明，不添加职业经历、技能评级或其他个人资料。经确认，设计已接入正式 [`/about`](http://127.0.0.1:3015/about)。

## 构图

| 部位 | 设计 |
| --- | --- |
| 顶部导航 | 复用最新确认的山水背景导航形式，左侧返回首页，右侧朱印与关于；不包整条纸面 |
| 宣纸小序 | 暖米色宣纸、细内框与自然阴影；沿用既有水墨题头图片，已删除上下画轴、轴头和丝绦 |
| 卷首 | 保留“关于这间小屋 / 写代码，也写生活”，加右侧竖题、朱印与卷首落款；手机将标题分为“关于 / 这间小屋” |
| 正文 | “小屋里的寻常日子 / 为走过的时间留白 / 山水有相逢”三段，原有正文完整保留；章签、细分隔与边注形成阅读节奏 |
| 页边落款 | 博主头像放入有纸边的照片，配纤维胶贴、署字小印、昵称和原有角色；页面底部仍保留署名 |
| 三张小笺 | 文章、闲语、光影三个正式页面入口。统一暖米纸，配不同景片、文语影题签、背纸、折角与细色线；没有虚构数量或文章数据 |
| 相逢收尾 | 信封、敬候文字与可翻动上盖组成留言入口，指向现有 `/guestbook` |

桌面纸面最大 1100px，正文与 226px 页边落款并列；落款按正常文档流排列，取消悬浮索引、章节选择和阅读进度。760px 以下落款移到正文前，以横向小笺呈现。纸张长度由内容决定，没有固定空白下半页。

## 动效与操作

- 页面直接呈现完整内容，删除展卷、标题入场、章节渐入及重播按钮。
- 纸笺悬停或键盘聚焦时抬升、显色、背纸错开、折角展开；桌面指针带来克制的轻倾。
- 头像照片在落款笺悬停时轻回正；留言信封上盖翻起，箭头轻移。夜色采用暖褐纸、浅墨与淡朱。
- 顶部工具与站内昼夜按钮同步状态。窄屏目录支持展开、Escape 关闭及焦点恢复。
- 减少动态效果时停用倾斜与位移，保留静态设计及功能。无 JavaScript 时正文和页面入口仍可阅读与使用。
- 头像使用现有公开资源，不额外下载；尚未加载或不可达时以昵称首字母作纸面落款，避免空白照片框。

## 验证

- 日夜两色 × 1440、1280、1024、768、600、520、485、390、360px 共 18 组：根文档与纸面、落款、小笺、留言入口、标题均未溢出。
- 五段原文、三个入口、ID 唯一性、中文标题换行、手机目录与 Escape 焦点恢复通过；确认索引、进度、画轴、重播及入场动画均已移除。
- 悬停题签显色/折角、减少动态效果、头像失败兜底、无脚本阅读通过；浏览器未捕获脚本异常。
- `node --check` 与 `npx tsc --noEmit` 通过；`npx next build` 成功生成 37 个页面，期间有 Supabase 网络连接失败日志，命令退出 0。
- `npx vitest run`：68 个文件、333 个断言通过，但有 5 个既有 `DailyQuote.tsx:105` 的动画 API 未处理异常，命令退出 1；不将全量测试标记为通过。
