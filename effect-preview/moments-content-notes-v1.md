# 闲语页 · 日常札记设计稿

[打开 HTML 设计稿](moments-content-notes-v1.html)

## 设计方向

- 题头沿用已确认文章页的比例、山水淡画、行书标题、左侧朱线和右上朱印，保留闲语页的“片言只语，也是一日光景”。
- 正文采用同宽、对齐的宣纸札记卡片；日期独立置于左侧，作者、文字和操作栏形成稳定层次。
- 桌面配图紧邻文字右侧，使用纸边和少量旋转叠放；手机改为文字下方，避免遮挡。
- 包含 0、1、2、3、5 张配图示例。多于 3 张时保留三张叠放预览，以“+N”提示剩余照片，全部照片可在看图窗口切换。照片下不添加说明小字。
- 年份和月份索引桌面置于左侧，手机改为横排。点击年份定位到对应札记，所有年份的札记持续展示；再次点击当前年份折叠或展开月份目录。加入 2025 年示例以体验跨年选择。正文保留淡墨引号、纸纤维、细线和朱印细节。

## 可以体验

顶部可切换日色／夜色、桌面／手机布局和访客／登录演示。

卡片有轻微抬起、随鼠标位置变化的纸面光晕；照片随悬停轻微展开，底部细线渐进延伸。滚动时卡片依次显现。键盘聚焦也会显示反馈，低动态模式关闭位移动效；禁用 JavaScript 时正文默认可见。

点击照片打开看图窗口，左右方向键切换，Escape 关闭并返回原按钮。登录演示可点赞、展开回应和添加留言；留言只保留在当前预览中，不写入网站数据。

## 本次范围

这是独立 HTML 视觉设计稿，文案为示例，配图使用仓库现有山水素材示意。正式 `/moments` 页面等逐页确认后再实施。

## 本轮调整

- 纸页顶部使用一条连续的静态朱线，不分段、不突出当前页面，不随滚动变化或吸顶。
- 年份按钮只滚动定位正文并展开对应月份目录；折叠仅作用于目录，不隐藏说说。支持键盘操作及月份深链接。
- 喜欢、回应及数字统一行高与对齐，心形图标使用独立固定尺寸。
