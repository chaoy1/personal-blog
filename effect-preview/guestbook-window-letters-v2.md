# 留言页设计方案 · 山窗来信

预览：[打开独立 HTML 设计图](http://127.0.0.1:3016/effect-preview/guestbook-window-letters-v2.html)。

本稿依据当前 `/guestbook` 的山水题头、宣纸主体、留言与书写双栏关系设计。正式路由、留言数据、登录、回复接口和权限均未修改。旧设计稿保留，时间轴暂停继续调整。

## 构图与细节

| 区域 | 设计 |
| --- | --- |
| 山水题头 | 继续使用站内水墨山景与“来者有言，皆收于此”；保留卷五标识、书法标题与朱印，加右侧题跋和克制的英文落款 |
| 纸面 | 桌面最大 1100px，左侧阅读区与右侧 292px 书写引导区；纸面、信笺与页边采用三个明度层次，内容结束即收束页底 |
| 来信 | 左侧装订线与穿线环串起统一暖米色信笺；侧签、个人方印、无框中文日期、淡竹纹与右下曲面折角构成装帧，正文自然撑高 |
| 回信 | 松色小纸条附在原笺内，用纤维胶贴、复字小印和轻微倾角区分；原笺静态沿用松色，悬停时换用随机装帧色 |
| 山窗 | 保留“山窗寄语 / 窗外有山，纸上有话”；拱形窗框、双线木边、窗棂与原站水墨远山组成阅读停顿处 |
| 书写入口 | 朱色双细框按钮与可翻起的信封线稿；“展笺书写”打开信纸弹层 |
| 分页 | 置于来信区结尾，以小型朱色页签表达当前页，翻页后焦点回到来信标题 |
| 书写弹层 | 纸边细框与统一左边线；题头、简短说明与中文日期、36px 格线正文、敬上落款和寄出按钮依次排列，最多 500 字 |

760px 以下变为单列，山窗与书写入口置于来信前；390/375/360px 下进一步缩小窗景、保持入口全宽，信笺仍按内容高度排版。夜色采用深褐底纸、较浅信笺、暖墨文字与淡朱色操作。

## 动效

| 触发 | 表现 |
| --- | --- |
| 首次打开 / 重看展笺 | 山水横向显出（1.5s），标题轻入场，朱印随后落下；右侧山窗从中间打开 |
| 来信首次进入视野 | 纸页向下展笺，正文延迟显出；完成后静止 |
| 悬停或键盘聚焦来信 | 纸页抬升 4px、背纸微错位、竖线、方印与侧签随机显色；曲面折角由 25px 展至 41px，附笺轻回正；日期保持静止 |
| 指针移动 / 移出 | 桌面纸面随指针轻微倾斜（最大约 0.75°），移出后复位；不改变排版高度，触屏不依赖此效果 |
| 悬停书写入口 | 信封上盖翻起、入口轻抬，箭头提示寄送方向 |
| 打开书写面板 | 信纸展笺并聚焦正文，背景虚化；关闭时回到入口 |
| 减少动态效果 | 停用入场、循环加载及悬停位移，功能与静态内容保留 |

## 卡片装帧修订

依据“卡片太普通”、此前要求“卡片与背景要有区分”“增加悬停特效”和“不要过长”，来信正面、背纸与底纸保持独立层次。淡竹纹只作低浓度背景，不压住正文。本稿按最新截图统一纸色，随机颜色仅用于悬停装帧，继续保留中文日期与整理后的书写面板。

来信保留同一设计骨架，静态使用松色装帧；每次指针移入或键盘从卡片外进入时，随机选择装帧色；回信是独立附笺，避免原留言与回复混成一整块。SVG 折角具有曲面路径、渐变与折痕，每封使用独立渐变 ID。书写弹层、双栏与题头保持既有构图。

1440px 下六张示例纸页实测约 300 / 178 / 214 / 264 / 178 / 178px，高度随正文与回信变化；悬停不增加高度。装帧动画延续“展笺 → 显字 → 印记与附笺显出”的一次入场节奏。减少动态效果时停用倾斜、抬升和印记扩散。

## 统一纸色与随机悬停装帧

全部来信采用截图对应的暖米色纸面：正面为 `#fff2d9`，背纸为 `#e7d6b3`，静态边线为 `#b49b73`。同一主题下每封来信纸色一致，翻页、回复、重播或悬停均不会改变纸面。夜色统一使用茶褐纸面 `#584a35`；回笺与折角从统一纸色衍生。

左侧竖线、笺签与个人方印在悬停时随机使用朱砂、松绿、赭金、黛青、茶褐、灰梅六种低饱和装帧色，采用洗牌袋避免反复只出现同一种；重新移入可以换色，卡片内移动不换色。移出后恢复静态松色。键盘进入卡片也得到同样的随机反馈；夜色使用对应较亮的色值，触屏不依赖悬停。纸页抬升、指针轻倾、折角展开和印记扩散保留，减少动态效果时仅静态显色。

日期仍使用原有公历日期，显示为“二〇二六年 / 九月廿九”这样的中文书法落款，右对齐分为两行。日期没有圆框、边线、投影或旋转；年份轻淡，月日略大。辅助技术读到完整中文年月日，`datetime` 属性保留标准日期格式。无脚本静态来信也显示中文日期。

书写面板按“题头 → 一句书写说明与日期 → 格线正文 → 敬上落款 → 寄出”排布。标题、正文、署名和说明沿同一左边线；关闭、字数与寄出沿右边线。移除纵向题签、额外寄印、英文小字、行号、重复称呼和底部山景，保留纸纹、细框和朱色信封按钮。正文使用 36px 行高；连续在末尾输入时，书写区跟随到末行，编辑中间内容时保留滚动位置。弹层打开时锁住背景滚动，关闭后恢复；失败保留正文，寄送按钮的信封图形在重试后仍保留。

## 演示范围

顶部工具可切换日夜、三种身份和空/加载/错误/寄送失败状态。默认展示已登录访客，便于体验书写；未登录状态显示正式登录链接。所有新增留言、回信与收起留言只改变本页示例，刷新即可恢复，不向正式站点提交数据。

示意数据为十封来信，每页六封，默认形成六条与四条两页；新增第十三封时形成六条、六条、一条三页。页码、笺签序号与来信编号统一使用预览页容量，演示动态分页。正式实现采用同样的 `PAGE_SIZE = 6`，保留现有数据资源、缓存、回复树和删除权限；顶部演示工具与样例不进入正式页面。

关闭再打开保留未寄出的正文。寄送中禁用重复操作；失败保留内容并提示重试。收起来信先出现确认弹层，取消保留，确认后更新示例总数。文本输出转义，留言中的 HTML 作为文字显示。

- 日色/夜色 × 1440、1024、768、390、375、360px 共 12 组：纸页、侧栏和根文档没有横向溢出。
- 长正文、书写弹层边界、输入焦点、Tab 闭环、Escape、关闭恢复焦点、重开保留草稿通过。
- 回信、文本转义、翻页与分页焦点、寄送中状态、失败保留、成功插入及新增第三页通过。
- 未登录入口、博主演示收起与取消、空/加载/失败/重试、手机目录、减少动态效果通过。
- 禁用 JavaScript 时仍显示三封静态来信与回信，隐藏不可用演示入口并提供正式页面链接。
- 浏览器未捕获到页面脚本异常或资源失败。四张交付截图均在有限动画完成后保存。
- 本轮复测通过：三个独立 SVG 折角、无框日期与前后纸面色差；指针倾斜和移出复位、折角展开、悬停高度不变、键盘反馈及减少动态效果均已检查。更新卡片悬停截图。
- 统一纸色与悬停检查通过：日夜两色中每封纸色一致，悬停、翻页和新留言不改变纸面；同一封连续六次移入覆盖六种装帧色，移出恢复松色，键盘聚焦反馈通过。分页六条加四条、第二页编号 07 至 10、新增至十三条形成第三页通过。中文日期仍无框、无阿拉伯数字；手机书写、草稿与失败重试继续通过。
- `npx tsc --noEmit`、`npx next build` 通过。`npx vitest run` 的 67 个文件、340 个断言通过，但有 5 个既有 `DailyQuote.tsx:105` 的 `echo.animate is not a function` 未处理异常，命令退出 1；不将全量测试标记为通过。

## 正式实现（2026-10-01）

用户确认后，设计已接入 `/guestbook`。新增 `GuestbookLetter` 与 `lib/guestbook-design.ts`：统一纸色、六种随机悬停装帧色、中文日期、逐张入场和指针轻倾。生产配色每次进入随机选择并排除上一种，卡片内移动保持颜色；静态回复组件仅在留言页启用信笺形式。书写弹层采用整理后的格线、落款与信封按钮，继续保留原有提交、草稿、错误重试和过期请求处理。

- 使用实际页面组件与隔离的登录示例数据，检查六条加四条分页、编号、统一纸色、随机悬停、日夜两色及五种宽度、长正文、草稿与失败重试、回复及 HTML 转义。未写入正式留言库；正式页面读取原有留言。
- 正式构建的页面返回 HTTP 200，读取四条原有顶层留言；日夜两色与 1440、1024、768、600、520、485、390、360px 共 16 组无横向溢出，山窗标题不折断。约 500px 下采用小窗与全宽入口，功能入口使用原有身份与权限。
