# M05 后台照片管理页实施计划

## 目标

把 `/admin/photos` 分成相册、上传工作区和已有照片三段，让当前相册、队列状态和照片管理目标清晰可见；保留现有 Storage、数据库、说明、归档排序、编辑与删除行为。

## 任务

- [x] 先补充 `tests/admin-photos-page.test.tsx`：覆盖分段语义、加载/刷新、照片筛选、部分上传失败保留队列和切换相册保护。
- [x] 改造 `app/admin/photos/page.tsx`：增加页面/照片集合状态、当前相册筛选、排序、上传结果状态和队列保护，保留现有 API 行为。
- [x] 在 `app/studio.css` 增加 M05 页面作用域样式：三段工作区、照片管理网格、稳定缩略图、队列状态与 375px 响应式规则。
- [x] 运行目标测试、类型检查、全量测试和生产构建；记录既有 P02 posts 测试失败，不扩大范围修复。
- [ ] 只暂存 M05 文件，执行 diff/凭据检查，提交并推送到 `origin/main`，校验远端 SHA 与 ahead/behind。

## 验收

- 相册创建/选择、待上传队列和已有照片管理是三个明确工作段。
- 初次加载和刷新有明确状态，刷新不清空当前相册或上传队列。
- 部分上传失败只保留失败项，失败项可继续重试；保存成功项不重复提交。
- 照片搜索、相册筛选、排序和既有编辑/排序/删除入口可访问。
- 375px 下创建、选择、上传、重试和删除控件仍可达且无横向溢出。
