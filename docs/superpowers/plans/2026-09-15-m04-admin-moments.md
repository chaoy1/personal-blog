# M04 后台闲语管理页实施计划

## 目标

把 `/admin/moments` 收敛为一个可恢复、可观察的后台闲语工作台：编辑区始终可用，列表加载/刷新不清空编辑内容，保存、上传和列表操作分别反馈状态，并在切换编辑目标前保护未保存内容。

## 任务

- [x] 先补充 `tests/admin-moments-page.test.tsx`：覆盖编辑区可用、列表加载/刷新、保存状态、失败保留内容和未保存切换确认。
- [x] 改造 `app/admin/moments/page.tsx`：增加页面/列表状态、语义区域、保存状态、失败恢复与未保存编辑保护，保留现有上传、草稿、删除撤销和权限行为。
- [x] 在 `app/studio.css` 增加 M04 页面作用域样式：开放式闲语列表、状态提示、响应式编辑区与 reduced-motion 支持。
- [x] 运行目标测试、类型检查、全量测试和生产构建；记录既有 P02 posts 测试失败，不扩大范围修复。
- [ ] 只暂存 M04 文件，执行 diff/凭据检查，提交并推送到 `origin/main`，校验远端 SHA 与 ahead/behind。

## 验收

- 新建页在列表加载期间仍显示正文、配图选择和发布入口。
- 列表刷新保留当前编辑内容；初次加载失败不隐藏编辑入口，并提供重试。
- 保存中、成功、失败均有可访问状态；失败不清空正文和图片。
- 切换编辑目标或取消编辑前，未保存内容会进入统一确认流程。
- 375px 宽度下编辑区、上传队列和列表操作不发生横向溢出。
