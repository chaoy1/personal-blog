# M06 后台博主资料页实施计划

## 目标

把 `/admin/profile` 变成可理解、可恢复的博主资料工作区：加载时不允许对未知空值保存，头像/短字段/长文编辑保持稳定，保存与上传状态清楚，并在离开或快捷保存时保护未提交内容。

## 任务

- [x] 先补充 `tests/admin-profile-page.test.tsx`：覆盖加载骨架、资料编辑、保存失败保留内容、头像上传失败保留旧头像和快捷保存。
- [x] 改造 `app/admin/profile/page.tsx`：增加页面/上传/保存状态、语义区域、离开保护、快捷键和上传校验，保留创建资料与现有 API 契约。
- [x] 在 `app/studio.css` 增加 M06 页面作用域样式：身份区、长文编辑区、固定状态提示、错误/骨架与 375px 响应式规则。
- [x] 运行目标测试、类型检查、全量测试和生产构建；记录既有 P02 posts 测试失败，不扩大范围修复。
- [ ] 只暂存 M06 文件，执行 diff/凭据检查，提交并推送到 `origin/main`，校验远端 SHA 与 ahead/behind。

## 验收

- 初次加载展示稳定骨架，不把空值误当作可保存资料。
- 头像上传失败、资料保存失败和会话失效均保留当前编辑内容及旧头像。
- 脏状态靠近主操作显示，成功后更新基准；Ctrl/Cmd+S 复用保存流程。
- 查看关于页不会让当前编辑页丢失，刷新/关闭有未保存提示。
- 375px 下头像、字段和长文编辑仍单列可用。
