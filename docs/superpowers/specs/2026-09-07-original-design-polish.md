## 本次如何改善

### 首页：调整已有元素的关系

保持现有中轴构图。校准站名、描述、统计和每日一句的垂直节奏；对矮屏压缩空隙而非缩小所有文字。两侧题签保持原样式语言，统一字距、内边距与透明度。原山水画继续满幅展示，不用整页重遮罩降低画面亮度。

小字的可读性通过现有文字颜色和局部护字层改善。信息性小字目标不小于 12px，导航目标不小于 14px；纯装饰性英文小标不承担必要信息。正文与可操作文字应在实际背景上清晰可辨。

### 内容：细化纸面，不换版式

文章卡片继续使用编号、日期、标题、摘要、阅读入口结构。调整边框、内阴影、纸纹强度与间距，避免多层边框和阴影争抢注意力。照片保持现有数量与排列规则，统一留白和边框；缩略图裁切不改变灯箱里原图的完整展示。

各列表页沿用 `PageIntro`，统一其标题、说明、印章与内容区的距离。时间轴保留交错节点，校准夜间节点与日期标签的对比。留言、账户、登录页只统一相关纸面、输入框及焦点状态，不重写表单流程。

### 阅读：提升长文舒适度

保留正文居中、目录在外侧轨道的关系。桌面正文目标 18px、手机 17px，行高 1.9–2；长行最大约 38 个中文字符，最终以现有容器的内边距和实际文本测量校准。统一标题、段落、引用、列表、代码和表格间距。

不加入首字下沉、每级标题装饰图案或滚动自动隐藏导航。它们会改变已有阅读节奏，且不属于本轮必要精修。

### 动效：连续、轻巧、有边界

继续使用现有 `ScrollFX` 和 Canvas。卡片浮起幅度控制在 2–3px，交互过渡 180–240ms；内容浮现 450–650ms，分组错落 50–70ms，最多累计 210ms。优先调整现有实现，避免同一元素同时被 CSS 与 JS 写入 transform。

遵循现有 reduced-motion、save-data、页面可见性策略，保持 `null` 未解析状态与 `false` 禁用状态的区别。首屏内容不能依赖动画完成才能操作。不新增路由离场动画、背景多层视差或数字从零滚动。

对现有 Canvas 做一次同条件性能采样。只有采样确认绘制成本明显时才缓存重复光晕纹理；保持云雾形状与透明度，保留已存在的枫叶纹理缓存。不能以追求性能为由把整套氛围直接移除，也不能把“更多粒子”当作美化目标。

## 验收定义

第一判断标准：前后截图仍明显是同一个原设计，改善发生在文字清晰度、间距、纸面和交互细节。

必须检查 1440×900、1280×720、768×1024、390×844、360×800 的适用布局，明暗两种主题；每个公开路由在 390px 下满足根元素与 body 均无横向溢出。文章代码块、表格只在自身容器横向滚动。

菜单、搜索、灯箱、目录、主题切换和表单焦点行为不回退；低动态模式下内容立即可见。运行现有测试、typecheck 和生产 build。记录实际结果，构建通过不等于生产部署成功。
