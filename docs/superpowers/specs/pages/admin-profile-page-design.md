# M06：后台博主资料页设计规格

路由：`/admin/profile`

源码：`app/admin/profile/page.tsx`

模板：Owner Profile Settings

## 页面任务

让博主管理关于页所使用的头像、姓名、身份说明和个人介绍，并能理解修改会如何影响公开页面。

## 必须保留

- owner/profile 现有字段与保存流程。
- 头像选择、上传和预览。
- Markdown 或现有格式的个人介绍编辑。
- 脏状态、保存反馈和管理员权限。
- 与公开关于页既有数据来源的一致性。

## 信息层级

```text
页面标题 / 查看关于页
公开身份
├── 头像
├── 姓名 / 身份说明
└── 其他现有字段
个人介绍正文
保存状态 / 主保存操作
```

公开身份与长篇介绍是两个编辑尺度，但共同提交时必须清楚标记哪些字段已修改。

## 版式设计

- 使用 Default 容器，短字段与头像组成上区，长文编辑组成下区。
- 可提供轻量“公开效果”摘要，但不复制完整关于页作为第二套渲染。
- 长文编辑区优先保证行宽、字号和光标体验。
- 保存状态靠近顶栏或底部粘性操作区，避免长页面中丢失。
- 表单继续采用后台的纸色和墨线，不堆叠多个设置卡片。

## 组件边界

- `OwnerIdentityFields`：头像与短资料字段。
- `ProfileBioEditor`：长文内容。
- `AvatarUploader`：尽量与账户页复用上传行为。
- `DirtyStateGuard`、`Button`、`Feedback`：使用统一基础设施。

后台资料编辑与公开 `AboutColophon` 共享数据契约，不共享含副作用的组件。

## 状态

- 加载：字段骨架稳定，不允许在未知数据上直接保存空值。
- 未保存：持续显示，并在离开时确认。
- 头像上传中：旧头像继续可见。
- 保存成功：更新基准值并清除脏状态。
- 保存失败：保留所有输入和本地头像预览。
- 部分字段缺失：显示可编辑空值，不把缺失当错误。

## 交互

- “查看关于页”在新标签或安全返回路径中打开，不丢失未保存内容。
- 头像选择支持格式/大小反馈和重新选择。
- 保存快捷键与文章编辑器规则一致。
- 切换页面、刷新或关闭存在未保存内容时使用统一保护。
- 错误聚焦到对应字段，成功由 live region 宣告。

## 响应式

- 1440/1024：头像与短字段可横向组织，长文区单独占宽。
- 768：上区纵向排列，保存操作保持可见。
- 375：头像按钮、文件名、字段和错误提示均单列；长文本区有足够高度。

## 不在本页处理

- 不新增简历生成、社交数据同步或多身份档案。
- 不改写个人介绍内容，不改变公开字段的数据模型。
- 不把完整公开关于页嵌入后台。

## 验收

- 首次加载不会把空骨架误保存为真实资料。
- 上传/保存失败和会话失效均不会丢失正在编辑的内容。
- 公开关于页能正确消费保存结果，缺失字段不破坏构图。
- 375px 下长文编辑、头像上传和离开确认均可用。
