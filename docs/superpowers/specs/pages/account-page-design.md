# A02：账户页设计规格

路由：`/account`

源码：`app/account/page.tsx`

模板：Account Settings

## 页面任务

让已登录用户管理公开资料、头像和账户安全，并随时理解哪些修改尚未保存。

## 必须保留

- 昵称/资料编辑和头像上传。
- 密码修改及现有认证校验。
- 返回来源或返回博客能力。
- 成功、失败和进行中反馈。
- 未登录访问的现有保护与跳转逻辑。

## 信息层级

```text
账户标题 / 返回
个人资料
├── 头像
├── 昵称等字段
└── 保存资料
账户安全
├── 密码字段
└── 更新密码
```

个人资料和安全设置是两个独立任务，必须分区并各自拥有保存状态；不能用一个含糊的全页“保存”。

## 版式设计

- 使用 Default 或 Readable 容器，桌面可双区并列，移动端顺序堆叠。
- 头像编辑紧邻资料字段，上传说明和格式限制放在操作附近。
- 安全区使用更克制的边界和警示文案，不用红色装饰整块区域。
- 每区只保留一个主操作，未修改时主操作可禁用并说明原因。
- 页面外观延续纸面语言，但比公共内容页更功能化、更安静。

## 组件边界

- `AccountSection`：统一设置区标题、说明和操作位。
- `AvatarUploader`：预览、选择、上传和失败恢复。
- `Input`、`Button`、`Feedback`：复用基础组件。
- 页面负责脏状态、认证和提交顺序，不把密码与资料合并为同一表单。

## 状态

- 首次加载：使用稳定骨架；已有资料快照可直接展示。
- 未保存：清楚标记对应分区，离开时按全局脏状态策略提示。
- 上传中：保持旧头像至新头像成功，不显示破图。
- 保存成功：只清除对应分区脏状态。
- 保存失败：保留字段内容和预览，显示局部错误。
- 会话失效：说明需要重新登录并提供明确入口。

## 交互

- 头像文件选择后先本地预览，上传成功后再替换持久状态。
- 资料和密码可以独立提交，互不锁定。
- 密码管理提供必要的可见性切换与强度/要求说明，但不伪造强度结论。
- 离开含未保存内容的页面时使用统一确认对话框。
- 操作成功后焦点留在当前分区并由 live region 宣告。

## 响应式

- 1440/1024：两区可并列，但各表单仍保持合适输入宽度。
- 768：按资料、账户安全顺序单列。
- 375：头像操作纵向排列，文件名和错误文本可换行，按钮全宽。

## 不在本页处理

- 不新增账号注销、邮箱更换、社交绑定或多因素认证。
- 不改变认证和存储策略。
- 不加入管理员内容管理入口，除非现有权限导航已经提供。

## 验收

- 资料、头像和密码的 Loading/Success/Error 状态相互独立。
- 脏状态在保存成功、失败、取消和离开时行为一致。
- 头像上传失败不会丢失旧头像或表单内容。
- 375px 和键盘操作下所有表单、确认框和反馈可用。
