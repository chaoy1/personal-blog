# P01：首页设计规格

路由：`/`

源码：`app/page.tsx`

模板：Immersive + 分段式内容长卷

设计稿：`.design/home/home-hero-curated-scroll-v2.html`（首屏 V2「卷目山水」）

## 页面任务

首页不是数据仪表盘，而是进入“似水流年”世界的序章。首屏负责建立山水、书法和时间感；下半页负责把访问者自然带向文章、闲语、光影和留言。

## 首屏 V2 配方

设计稿是一张 1440×900 的固定画布，落地时转译为可流式收束的首屏。样式收口在
`app/home-hero-scroll.css`，全部选择器挂在 `.home-page .home-hero` 之下，只作用于首页首屏。

分层顺序（由深到浅）：

```text
远山披麻皴（TitleLandscape，multiply）
眉题柔光（.masthead::before）
眉题 / 站名 + 朱印 / 云气纹样 / 短句
两侧题签（HomeInscription）
卷目统计（三枚目录刻度 + 墨圈）
每日一句（含环形换句按钮）
下滑入卷
```

组件边界：

- `components/home/TitleLandscape.tsx`：站名背后的两层远山与一道云气，纯装饰。
- `components/home/Motif.tsx`：站名与短句之间的双层山水纹样，取代旧的抽象笔触。
- `components/home/HomeInscription.tsx`：左右题签共用形态（竖排题句 + 界格线 + 小印）。
- `components/DailyQuote.tsx`：保留既有重排逻辑，换句按钮改为环形墨轨。
- `components/ScrollHint.tsx`：保留滚动行为，文案改为「走下 · 入卷 / SCROLL TO ENTER」。

配色不写死十六进制值，只走 token：

- `--hero-ink` / `--hero-ink-soft`：文字主色与次色。
- `--hero-stroke-strong` / `--hero-stroke-soft`：云气、墨圈、界格线。
- `--hero-wash-far` / `--hero-wash-near`：两层远山的不透明度。
- `--hero-type-display`：题签、站名、卷目编号、短句共用展示字体。

站名保留全站既有字体，不回退成设计稿里的行书，以免首页与其它页面割裂。

窄屏收束：题签在 980px 以下隐去；卷目编号在 640px 以下去掉描边与叠影、墨圈随之收窄，
保证 375px 无横向溢出且三枚入口仍可单手点击。

两条容易踩空的排版约束：

- 题签是相对 hero 盒子绝对定位的，而 hero 顶部 = 导航 + `wrap` 上边距。
  所以偏移量必须取「设计稿画布值 − 上边距」（左 2px / 右 82px），
  才能让题签停在站名两侧的纵向区间内。直接照抄画布值会让它下探到卷目统计上。
- 卷目容器只收到内容宽度（690px）。若让它满宽，透明盒子会伸到右侧题签底下，
  看上去就像两块叠在一起；三枚刻度本身仍保持 156px 宽与 7/2/6px 的错位。

## 首屏占位与入场

首屏吃满导航以下的第一屏，而不是贴着内容高度：

- `.home-page` 把 `--wrap-pt` 归零，导航与画卷之间不再空出一段纸；
- `.home-hero` 用 `min-height: calc(100dvh - var(--nav-h))` 作为**下限**，
  内容更高时自然增高，不会被 `overflow: clip` 裁掉；
- 上下两条 `auto` 外边距平分剩余空间，标题块因此略高于视觉中心、
  下滑入口压在第一屏底部，元素之间不会被挤在一起。

入场按「纸 → 山水 → 题字」分三层递进，不允许整块硬闪：

```text
背影山水   1.5s   先铺纸面
远山       1.7s   随纸面显影
题签       1.5s (delay .1s)
眉题       0.9s
站名逐字   1.15s（自带 0.4s+0.17s/字）
朱印       1.25s
纹样       1.2s (delay .62s)
短句       1.05s
卷目/每日一句/下滑入口  1.15s
```

尾部三个区块原本各等 1.6s／1.8s／2s，统一压到 1s 上下，落墨才紧凑。
`prefers-reduced-motion: reduce` 时必须一次性就位：所有入场动画置 `animation: none`
（只动 animation，不动 transform —— 远山要靠 `translateX(-50%)` 居中）。

## 必须保留

- `qianli-bridge.jpg` 满幅山水。
- 居中站名、朱印、笔触和两侧题签。
- 文章、闲语、光影、留言的既有顺序。
- 统计入口、每日一句、向下浏览入口。
- 昼夜背景与现有轻量环境动画。
- 直接进入页面，不增加开屏遮罩或卷轴。

## 信息层级

```text
环境层：山水 / 云雾 / 枫叶 / 星月
主识别：站名 + 印章
主说明：站点短句
首要入口：文章 / 闲语 / 光影统计
情绪补充：每日一句
浏览提示：向下入卷
内容预览：文章 → 闲语 → 光影 → 留言
收尾：页脚落款
```

首屏只能有一个视觉中心：站名。统计和每日一句降低一级，不与站名争夺注意力。

## 版式设计

- 桌面首屏保持中轴构图，站名位于视觉中心略上位置。
- 两侧题签只负责建立纵向张力，透明度低于主标题。
- 首屏必要文字使用局部护字层，不给整张山水增加灰黑遮罩。
- 统计入口保持轻薄、可点击，不做三张厚重卡片。
- 内容区通过留白、题签或细墨线完成段落转换，不为每个 Section 再套外框。
- 每个预览 Section 只展示足以判断内容类型的信息，首页不替代完整列表页。

## 组件边界

建议拆分：

- `HomeHero`：站名、题签、统计、每日一句和 ScrollHint。
- `HomePostsPreview`：文章预览。
- `HomeMomentsPreview`：闲语预览。
- `HomePhotosPreview`：光影预览。
- `HomeGuestbookPreview`：留言预览。

拆分只降低 `app/page.tsx` 职责，不改变服务端并行取数和现有链接。

## 状态

- 数据正常：按既有顺序显示有内容的 Section。
- 全部为空：显示一处完整 EmptyState，不在每个 Section 重复“空”。
- 部分资源失败：保留成功资源，只在对应 Section 显示局部错误。
- Supabase 未配置：保留开发配置提示，但生产环境不展示技术配置步骤。
- 后台刷新：继续显示现有内容，不造成 Section 消失和页面高度骤变。

## 交互与动效

- 统计入口整块可点击，键盘焦点清晰。
- ScrollHint 只提示一次浏览方向，不持续抢夺注意力。
- Section reveal 保持 450–650ms，首屏标题无需等待 reveal 才可读。
- 图片 hover 只在 fine pointer 下产生 2–3px 位移。
- 每日一句切换按钮扩大 hit area，但视觉尺寸保持克制。

## 响应式

- 1440：完整题签和首屏构图，下滑入口在首屏内。
- 1024：中轴保持，统计间距收紧，题签不遮挡导航。
- 768：减少横向装饰占用，内容 gutter 使用 tablet token。
- 375：隐藏非必要纵向题签，站名不超过两行，统计仍为一组明确入口。
- 矮屏优先压缩垂直空隙，不统一缩小所有文字。

## 不在本页处理

- 不新增分类、热门排行、订阅弹窗或推荐算法。
- 不改变文章、闲语、相册和留言的数据库查询契约。
- 不增加背景视差、数字滚动或自动隐藏导航。

## 验收

- 修改前后仍明显是同一个首页构图。
- 首屏唯一主视觉是站名，必要文字在明暗主题真实背景上清晰。
- 1280×720 下每日一句与 ScrollHint 不重叠。
- 所有内容预览的标题、日期和入口层级一致，但视觉形态不完全相同。
- 375px 无根节点横向溢出，必要操作均可单手点击。
