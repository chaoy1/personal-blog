# P03：文章详情页设计规格

路由：`/posts/[slug]`

源码：`app/posts/[slug]/page.tsx`、`app/posts/article-detail.css`、`components/MarkdownView.tsx`、`components/ReadingCompanion.tsx`、`components/Comments.tsx`

模板：Reading（宣纸批注版）

版式来源：`effect-preview/article-xuan-reading.html`。文章是一张宣纸，卷首以行书起笔，正文居中偏左，批注轨落在纸面右侧的栏内，卷尾另有收束。

## 页面任务

提供适合中文长文的持续阅读环境，让标题、摘要、正文、目录和评论自然递进。视觉重点从全站山水转向文章本身，但仍保留宣纸与墨色气质。

## 必须保留

- 服务端文章读取、Metadata、canonical 和结构化数据。
- Markdown、GFM、标题锚点、代码、表格、图片和引用能力。
- 桌面外侧 Reading Companion、阅读进度和目录。
- 评论、回复和登录状态。
- 后台预览与公开文章共享的 Markdown 排版契约。

## 信息层级

```text
返回与定位：ArticleNav
卷首：序号（第 N 篇 · 手记） / 行书标题 + 楷书副题 / 摘要 / 日期与阅读时长
卷首下沿：全文字数与英文题记
正文：Markdown 内容，收尾处「读到这里 · 毕」
批注轨：目录 / 已读进度 / 手写批注
卷尾：卷尾签 / 推荐阅读 / 评论 / 落款
```

标题是页面最强信息；摘要是它的注脚，Metadata 与字数只作小字旁注，不形成第二条标题线。
卷首的序号、日期、阅读时长、全文字数全部来自真实数据；标题若含自然停顿（逗号、冒号、竖线）则在停顿处折成行书起笔 + 楷书收束，否则整句用楷书落笔。

## 版式设计

- 纸面 `min(1180px, 100%)`，桌面正文实际行宽约 725px，阅读行宽上限 730px。
- 桌面正文 `19px / 2.02`，首段 `21px / 1.95` 并落一个朱色首字；移动端 `17px / 1.95`。
- 正文与卷首共用同一条左对齐线；纸面变宽时正文不居中漂移。
- 中文长行目标约 35–40 个汉字，以真实字体测量校准。
- H2 编号 + 细线、H3 菱形起笔、段落、列表、引用、代码和表格使用固定纵向节奏。
- 图片可以突破正文行宽但不得突破纸面；图注回到正文对齐线。
- 代码块和表格只在自身容器滚动。

## Reading Companion

- 批注轨是纸面内的第二栏（225px），不再脱离纸面悬浮。
- 目录不覆盖文章正文，也不挤压 730px 阅读宽度。
- 当前章节以朱色菱形和墨色文字表达，不使用高饱和背景块。
- 锚点落点预留固定导航高度。
- 剩余宽度不足以同时容纳 730px 正文与完整轨道（约 1160px 以下）时收起轨道，改用正文顶部的「卷内目录」入口。

## Markdown 视觉语言

- 首段落一个朱色首字，作为整篇的入口。
- H2 是章节转换：带两位编号，右侧接一道淡去的水线。
- H3 是章节内部层级，只用一枚朱色菱形起笔，不重复 H2 的编号与长线。
- 引用使用单一朱色竖线、浅纸色底和一处收得很淡的引号。
- 有序列表用两位编号与小字间距表达顺序；无序列表只染朱色圆点。
- `---` 渲染成「续」字签分隔线，表示换节而非结束。
- 正文结束有明确的「读到这里 · 毕」，与推荐、评论分开。
- 行内代码与代码块区分明确，暗色主题保持语法可读。
- 链接具有非颜色提示；访问过的链接不降低到不可读。

## 组件边界

- `ArticleNav`：返回、文章定位和必要的次导航。
- `MarkdownView`：Markdown 语义渲染与标题锚点。
- `ReadingCompanion`：阅读进度、目录和当前章节状态。
- `Comments` / `CommentThread`：评论输入、列表与回复关系。
- 页面负责文章元数据、not-found 和结构化数据，不让客户端阅读组件重复请求文章正文。

## 评论区

- 与正文之间有明确收束空间，不把评论误认为文章续文。
- 评论数量、登录提示、输入区和评论树按重要性排列。
- Phase 2 缓存提供首帧评论；后台刷新不清空评论树。
- 回复关系通过缩进和细线表达，移动端限制最大嵌套视觉缩进。

## 状态

- 文章不存在：使用 Next notFound，不渲染空纸面。
- 评论首次加载失败：不影响正文阅读。
- 评论后台同步失败：保留现有评论并提供重试。
- 图片失败：保留替代文本和稳定占位高度。

## 交互

- 目录点击后将目标标题置于固定导航下方，并同步 URL 锚点。
- 浏览器前进/后退恢复章节与滚动位置，不重复播放整页入场动画。
- 评论提交、回复和删除只锁定对应操作，不影响正文阅读。
- 键盘用户可以跳过目录直达正文，目录当前项不只依赖颜色表达。
- reduced-motion 下阅读进度仍可用，但关闭非必要位移和滚动动画。

## 响应式

- 1440：正文与批注轨同时在纸面内完整显示。
- 1160：纸面内已放不下 730px 正文 + 完整轨道，收起轨道，改用卷内目录入口。
- 768：纸面使用 tablet gutter，卷首图退为横向画卷，图片不溢出。
- 375：标题收敛为移动 H1，代码和表格局部滚动，评论缩进减小。

## 不在本页处理

- 不新增强制封面、阅读计数或推荐算法。
- 首字下沉只作用于正文首段，不改动标题锚点规则。
- 不改变 Markdown 存储格式和标题锚点规则。
- 不加入滚动隐藏导航或路由离场动画。

## 验收

- 长文连续阅读不需要频繁左右移动视线。
- 无目录、短目录、长目录和重复标题均能正常工作。
- 超长链接、宽表格、代码块和大图不造成根节点溢出。
- 评论加载或刷新不会改变正文位置。
- 后台预览和公开文章的正文排版没有实质差异。
