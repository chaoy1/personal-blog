# P03：文章详情页设计规格

路由：`/posts/[slug]`

源码：`app/posts/[slug]/page.tsx`、`components/MarkdownView.tsx`、`components/ReadingCompanion.tsx`、`components/Comments.tsx`

模板：Reading

## 页面任务

提供适合中文长文的持续阅读环境，让标题、摘要、正文、目录和评论自然递进。视觉重点从全站山水转向文章本身，但仍保留宣纸与墨色气质。

## 必须保留

- 服务端文章读取、Metadata、canonical 和结构化数据。
- Markdown、GFM、标题锚点、代码、表格、图片和引用能力。
- 桌面外侧 Reading Companion、阅读进度和目录。
- 评论、回复和登录状态。
- 后台预览与公开文章共享的 Markdown 排版契约。

## 信息层级

```text
返回与定位：ArticleNav
文章身份：类型 / 日期 / 状态
核心：标题
导读：摘要
正文：Markdown 内容
辅助轨：阅读进度 / 目录
文章收束：结尾信息
交流：评论与回复
```

标题是页面最强信息；摘要比正文略淡，Metadata 不应形成另一条强标题。

## 版式设计

- 正文实际行宽约 680px，文章纸面约 780px。
- 桌面正文 `18px / 1.95`，移动端 `17px / 1.9`。
- 中文长行目标约 35–40 个汉字，以真实字体测量校准。
- H2、H3、段落、列表、引用、代码和表格使用固定纵向节奏。
- 图片可以突破正文行宽但不得突破文章纸面；图注回到正文对齐线。
- 代码块和表格只在自身容器滚动。

## Reading Companion

- 只在剩余宽度足够容纳完整轨道时显示。
- 目录不覆盖文章正文，也不挤压 680px 阅读宽度。
- 当前章节状态以墨色和细线表达，不使用高饱和背景块。
- 锚点落点预留固定导航高度。
- 移动端隐藏外侧轨道，必要时提供文章顶部的紧凑目录入口。

## Markdown 视觉语言

- H2 是章节转换，使用明显上留白和一处克制装饰。
- H3 是章节内部层级，不重复 H2 的印章或长线。
- 引用使用单一墨线和浅纸色，不叠加大引号、边框和阴影。
- 行内代码与代码块区分明确，暗色主题保持语法可读。
- 链接具有非颜色提示；访问过的链接不降低到不可读。

## 组件边界

- `ArticleNav`：返回、文章定位和必要的次导航。
- `MarkdownView`：Markdown 语义渲染与标题锚点。
- `ReadingCompanion`：阅读进度、目录和当前章节状态。
- `Comments` / `CommentThread`：评论输入、列表与回复关系。
- 页面负责文章元数据、not-found 和结构化数据，不让客户端阅读组件重复请求文章正文。

## 评论区

- 与正文之间有明确收束空间，不把评论误认为文章续文。
- 评论数量、登录提示、输入区和评论树按重要性排列。
- Phase 2 缓存提供首帧评论；后台刷新不清空评论树。
- 回复关系通过缩进和细线表达，移动端限制最大嵌套视觉缩进。

## 状态

- 文章不存在：使用 Next notFound，不渲染空纸面。
- 评论首次加载失败：不影响正文阅读。
- 评论后台同步失败：保留现有评论并提供重试。
- 图片失败：保留替代文本和稳定占位高度。

## 交互

- 目录点击后将目标标题置于固定导航下方，并同步 URL 锚点。
- 浏览器前进/后退恢复章节与滚动位置，不重复播放整页入场动画。
- 评论提交、回复和删除只锁定对应操作，不影响正文阅读。
- 键盘用户可以跳过目录直达正文，目录当前项不只依赖颜色表达。
- reduced-motion 下阅读进度仍可用，但关闭非必要位移和滚动动画。

## 响应式

- 1440：正文与 Reading Companion 同时完整显示。
- 1024：根据安全宽度决定隐藏侧轨，不缩窄正文到不可读。
- 768：文章纸面使用 tablet gutter，图片不溢出。
- 375：标题收敛为移动 H1，代码和表格局部滚动，评论缩进减小。

## 不在本页处理

- 不新增首字下沉、强制封面、阅读计数或推荐算法。
- 不改变 Markdown 存储格式和标题锚点规则。
- 不加入滚动隐藏导航或路由离场动画。

## 验收

- 长文连续阅读不需要频繁左右移动视线。
- 无目录、短目录、长目录和重复标题均能正常工作。
- 超长链接、宽表格、代码块和大图不造成根节点溢出。
- 评论加载或刷新不会改变正文位置。
- 后台预览和公开文章的正文排版没有实质差异。
