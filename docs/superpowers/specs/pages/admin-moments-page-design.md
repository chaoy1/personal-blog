# M04：后台闲语管理页设计规格

路由：`/admin/moments`

源码：`app/admin/moments/page.tsx`

模板：Composer + Admin Collection

## 页面任务

让博主快速发布一条闲语，并在同一上下文中浏览、编辑或删除既有内容。

## 必须保留

- 闲语正文与图片发布能力。
- 既有闲语列表、编辑和删除。
- 上传、提交和操作反馈。
- 管理员权限与现有数据结构。
- 已有草稿或脏状态保护（如当前实现存在）。

## 信息层级

```text
页面标题
新闲语编辑区
├── 正文
├── 图片
└── 发布
管理工具 / 状态筛选
既有闲语列表
└── 内容 / 时间 / 状态 / 操作
```

编辑区是页面首要任务，管理列表次之；编辑已有闲语时必须明确当前正在修改哪一条。

## 版式设计

- 桌面可以上方编辑、下方列表，或主编辑区与窄列表并列；选择以现有代码改动最小者为准。
- 编辑区使用一张连续纸面，不把正文、图片和发布按钮拆成多卡片。
- 列表条目采用紧凑管理行，图片只显示小型稳定缩略图。
- 发布主操作使用朱印强调；删除保持低权重危险操作。

## 组件边界

- `MomentComposer`：正文、图片选择、草稿和提交。
- `MomentAdminList` / `MomentAdminItem`：管理集合与单条操作。
- `ImagePicker`：如与照片后台行为一致则复用上传基础能力，不强行共用业务组件。
- `ConfirmDialog`、`Feedback`：统一行为。

## 状态

- 列表加载与编辑区可用性分离；列表刷新不清空草稿。
- 图片上传、闲语发布和列表操作分别显示局部状态。
- 编辑模式明确显示“正在编辑”并提供取消返回新建。
- 发布成功后根据现有行为清空编辑区并局部插入列表。
- 失败保留正文和图片选择。
- 空列表不隐藏发布入口。

## 交互

- 中文输入法 composition 期间快捷提交不触发。
- 切换编辑目标前若有未保存内容，使用统一确认。
- 删除显示摘要或日期以确认目标。
- 图片移除只影响当前草稿，不立即删除已保存资源，除非现有流程明确如此。
- 发布期间不锁住后台导航。

## 响应式

- 1440/1024：编辑区与管理列表保持清楚分段。
- 768：上下排列，编辑区优先。
- 375：按钮全宽或分两行；缩略图、时间和操作不挤压正文。

## 不在本页处理

- 不新增定时发布、批量管理、内容推荐或社交数据分析。
- 不改变图片存储和闲语 schema。
- 不把闲语编辑器升级为文章级富文本工具。

## 验收

- 新建、编辑、取消、删除、上传失败和发布失败都不丢失无关状态。
- 列表后台刷新不导致编辑区跳跃或清空。
- 长文本、多图和空列表布局稳定。
- 375px 可以完成完整发布与管理流程。
