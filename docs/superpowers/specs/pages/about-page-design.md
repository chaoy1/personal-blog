# P08：关于页设计规格

路由：`/about`

源码：`app/about/page.tsx`、`components/PageIntro.tsx`

模板：Readable Profile Scroll

## 页面任务

以克制、可信的方式介绍博主本人、博客缘起和持续书写的态度。页面应像一篇自序与落款，而不是个人简历仪表盘。

## 必须保留

- 当前山水书法题头及其专属字体表达。
- Markdown 个人介绍正文。
- 头像、姓名、身份说明和落款区域。
- 昼夜主题下的纸面和墨色关系。
- 现有内容来源，不凭设计重构虚构经历或信息。

## 信息层级

```text
页面题头 / 自序
个人介绍正文
章节分隔
博主落款
├── 头像
├── 姓名 / 身份
└── 简短署名信息
```

正文是信息主体，题头建立气质，落款完成身份确认。头像不应成为比文字更强的社交资料卡。

## 版式设计

- 使用 Readable 容器形成连续阅读，不把每段内容拆成卡片。
- PageIntro 与正文之间保留较大的章首留白。
- Markdown 标题、段落、引用、列表和链接统一采用文章排版规则的轻量版本。
- 落款通过细线、印章色和横向留白收束全页。
- 当前专属书法字体只作用于已约定的标题/描述范围，避免全页可读性下降。

## 组件边界

- `PageIntro`：沿用受控变体，不在页面复制题头结构。
- `Prose`：复用 Markdown 基础排版规则。
- `AboutColophon`：只负责头像、身份与落款，不承担数据请求。

页面数据仍由现有 owner/profile 来源提供，不建立第二套个人资料模型。

## 状态

- 首次加载：题头骨架与正文宽度一致，避免大面积高度变化。
- 后台刷新：保留现有正文，不闪回空白。
- 资料缺失：隐藏缺失字段并保持完整构图，不显示 `undefined` 或破图。
- 头像失败：使用姓名首字或稳定的纸面占位。
- 错误：有缓存时保留；无缓存时用短说明和重试，不把技术错误放入正文。

## 交互

- 正文链接具备明确 hover、focus 和 visited 区分。
- 不加入无意义的滚动动画；章节显现仅使用轻淡入并尊重 reduced-motion。
- 头像和落款除非存在真实目标，否则不伪装成可点击元素。
- 锚点跳转后标题不被固定导航遮挡。

## 响应式

- 1440/1024：正文维持 Readable 行宽，外侧留白承载氛围背景。
- 768：题头字号收敛，正文与落款间距减少一级。
- 375：书法标题不溢出；头像与署名可上下排列；正文最小字号和行高保持可读。

## 不在本页处理

- 不新增技能条、项目墙、时间线、社交数据或下载简历。
- 不改写用户提供的个人介绍内容。
- 不替换现有山水、书法、宣纸和落款构图。

## 验收

- Markdown 常见元素都形成清晰但不过度的层级。
- 资料完整、部分缺失、无头像和加载失败时构图均成立。
- 375px 下标题、长链接和代码片段不造成横向溢出。
- light/dark 中书法标题、正文和落款均达到可读对比度。
